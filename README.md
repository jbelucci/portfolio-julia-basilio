# Portfólio profissional — Júlia Basilio Belucci

Site local de portfólio focado em processos, sistemas, operações, qualidade, dados e automação.

## Personalizações pendentes

- Em `index.html`, troque `seuemail@exemplo.com` pelo seu e-mail profissional.
- Quando os sistemas estiverem prontos, atualize as demonstrações visuais de BugFlow, ReqFlow e LeadFlow com imagens reais.
- Inclua links de LinkedIn, GitHub e currículo em PDF quando quiser disponibilizá-los.

## Prévia local

Abra `index.html` em qualquer navegador. O site não requer instalação de dependências.

## Estrutura

- `index.html`: conteúdo e estrutura do portfólio
- `styles.css`: visual responsivo e animações
- `script.js`: menu mobile, revelação de conteúdo e currículo interativo
- `logo.svg`: monograma J exclusivo nas cores do portfólio
