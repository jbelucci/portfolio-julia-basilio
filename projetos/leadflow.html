Documentação do projeto

Sobre

A ORVIA é um projeto demonstrativo desenvolvido para explorar a estruturação de processos comerciais, regras de negócio, automação e indicadores operacionais em uma única interface.

O problema

Pequenas e médias empresas frequentemente acompanham oportunidades comerciais utilizando planilhas, mensagens e controles separados.

  • Informações dispersas
  • Falta de acompanhamento
  • Dificuldade para medir conversão
  • Perda de follow-ups

A proposta

Centralizar cadastro de leads, acompanhamento do funil, gestão por vendedor, pipeline, resultados comerciais e indicadores operacionais.

Os dados registrados durante a operação alimentam automaticamente os dashboards.

Meu papel

Projeto de portfólio voltado à análise de processos, levantamento de requisitos, regras de negócio, automação, experiência do usuário, indicadores operacionais e estruturação de sistemas.

Fluxo analisado

Entrada do lead → Qualificação → Proposta → Negociação → Ganho ou perda → Indicadores

Principais regras de negócio

  • Leads ganhos alimentam receita.
  • Leads em andamento alimentam pipeline.
  • Cada lead pertence a um vendedor.
  • Dashboards por vendedor usam seus próprios registros.
  • Novos registros atualizam os indicadores automaticamente.

Tecnologias

HTML / CSS / JavaScript
Interface e comportamento da aplicação.

LocalStorage
Persistência local dos dados da demonstração.

GitHub Pages
Hospedagem do projeto.

A arquitetura foi pensada para permitir futura substituição do LocalStorage por uma base PostgreSQL/Supabase.

Todos os nomes, empresas, valores e registros utilizados na demonstração são fictícios.

Status do projeto

Versão atual: Protótipo demonstrativo interativo.

Próximas evoluções: banco de dados real, autenticação, histórico completo de movimentações, automações e relatórios mais avançados.
