Documentação do projeto

Sobre

A ORVIA é um projeto demonstrativo de organização comercial. Uma única base fictícia alimenta os leads, o funil, os indicadores e as visões por vendedor.

O problema

Controles separados tornam a operação mais lenta e dificultam a leitura de prioridades, resultados e próximos passos.

A proposta

Centralizar cadastro, acompanhamento, regras do funil e indicadores em uma interface clara para a operação comercial.

Critérios do funil

Fórmulas dos indicadores

Leads ativos

Oportunidades que não estão em Ganho ou Perdido.

Conversão

Vendas ganhas ÷ total de leads que entraram no período × 100.

Receita fechada

Soma dos valores dos leads Ganhos pela data de fechamento.

Pipeline

Soma dos valores das oportunidades abertas que entraram no período.

Ticket médio

Receita fechada ÷ quantidade de vendas ganhas.

Decisões de produto

Uma única fonte de dados

Dashboard, funil, vendedores e perfis usam os mesmos registros para evitar divergências.

Visão geral e individual

A operação pode ser lida no conjunto ou por responsável comercial.

Definições contextuais

Ícones de informação explicam indicadores e etapas onde eles aparecem.

Atualização automática

Ao cadastrar ou editar um lead, os indicadores relacionados são recalculados imediatamente.

Limite desta versão demonstrativa

Leads, origem e pipeline são filtrados pela data de entrada. Receita, vendas ganhas e ticket médio usam a data de fechamento. Como não há histórico de mudança de etapa, o pipeline usa as oportunidades abertas cuja entrada pertence ao período selecionado.

Tecnologias

HTML, CSS e JavaScript para interface e comportamento. LocalStorage para manter os dados desta demonstração no navegador.
